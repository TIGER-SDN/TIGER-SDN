# TIGER-SDN

TIGER-SDN is a research project exploring Explainable AI (XAI) techniques applied to Software-Defined Networking (SDN).

## Overview

This repository contains code and experiments for analyzing and interpreting AI/ML models used in SDN environments, with a focus on explainability and transparency.

## Getting Started

### Prerequisites

- Python 3.x
- Jupyter Notebook

### Installation

```bash
git clone https://github.com/TIGER-SDN/TIGER-SDN.git
cd TIGER-SDN
```
